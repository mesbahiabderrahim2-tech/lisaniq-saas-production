# Mission

Deliver an experience that allows a marketing agency to:

1. Discover LisanIQ.
2. Trust LisanIQ.
3. Register in less than 2 minutes.
4. Upload their first dataset.
5. Receive AI insights.
6. Understand the value.
7. Upgrade confidently.
8. Continue using LisanIQ every week.

Every interaction should increase confidence.

Never increase confusion.

# MVP Rules

The MVP must NEVER include features that do not improve the journey.

Every feature must answer:

Does this help the customer reach value faster?

YES → Build.

NO → Postpone.
